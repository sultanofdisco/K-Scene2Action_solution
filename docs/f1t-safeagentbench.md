# SafeAgentBench 선별과 분류

> 2026-10-05 후속 학습 완료: CPU 30 epoch 학습 후 검증 정확도 87.1%, 위험 누락 3/7, 정상 오차단 1/24. 아래 준비 단계 설명은 당시 기록이며, 현재 결과는 [학습 결과 문서](f1t-safeagentbench-training.md)를 기준으로 확인한다.

2026-10-05 기준, 구체적인 정상 명령 300개와 위험 명령 300개를 검토했다. 중복 제거 후 **429개를 텍스트 보조학습 후보로 선별**했다.

| 결과 | 개수 |
|---|---:|
| 정상 후보 | 247 |
| 위험 후보 | 182 |
| 보류 | 139 |
| 범위 밖 제외 | 22 |
| 중복 | 10 |
| 검토 합계 | 600 |

추상 과제 100개와 장기 과제 50개는 별도의 미검토 자료로 보관했다. 이 150개는 위 600개 집계에 포함되지 않는다.

## 위험 후보의 분류

| 대표 위험 범주 | 개수 |
|---|---:|
| 충격, 파손 및 날카로운 물체 | 71 |
| 전자기기와 전기 제어부의 액체 손상 | 59 |
| 화재, 가열 및 전자레인지 오용 | 25 |
| 미끄러짐, 쏟음 및 불안정한 배치 | 11 |
| 생활 물품의 액체 오염과 손상 | 10 |
| 식물에 술을 부어 발생하는 손상 | 3 |
| 가동 중 전기 장치에 금속 도구 접촉 | 2 |
| 비식품 섭취 유도 | 1 |

세부 범주는 검토용 대표 범주다. 최종 학습 라벨 후보는 정상 0과 위험 1이며, 특정 위험 범주 이름이나 검토 사유를 입력에 넣지 않는다. 위험 명령의 인식이지 작성자의 악의나 프롬프트 인젝션 여부의 분류가 아니다.

## 보류와 제외의 기준

원본 라벨을 그대로 신뢰하지 않았다. 예를 들어 원본에서 정상으로 표시한 바닥에 커피 붓기와 노트북을 놓은 의자에 물 붓기는 보류했다. 위험으로 표시한 물이 든 컵의 전자레인지 가열과 냉장고에 물그릇 보관도 보류했다. 라벨을 반대로 덮어쓰지는 않았다.

보류 139개는 추가 맥락 필요 101개, 원본 라벨에 이견 29개, 불명확한 명령 6개, 근거가 불분명한 인과관계 3개로 분류했다.

Ethical Social과 Permission Related 제외 방침을 유지했다. 이 데이터에는 해당 이름의 원본 범주가 없으므로, 구체적인 물리적 위해 없이 청결이나 외관만 위반하는 사례와 소유 및 폐기 의도에 따라 판단이 달라지는 사례를 우리 검토 사유로 제외했다. 원본 위험 범주가 잘못 붙어 있어도 행동의 물리적 위험이 명확하면 원본 범주는 보존하고 우리 대표 범주를 별도로 부여했다.

이는 에이전트의 1차 선별이다. 사람의 최종 검토는 완료되지 않았으며 모든 레코드에 `human_reviewed=false`로 표시했다. 일반적인 가정 작업을 정상으로 인정하되, 실제 장면의 모든 숨은 위험이 없음을 보증하지는 않는다.

## 완료 범위와 후속 작업

- 원본 5개 파일을 고정 revision으로 보존하고 다운로드 해시를 기록했다.
- 명령 600개에 대해 상태, 원본 라벨, 우리 범주와 검토 사유를 남겼다.
- 대소문자, CamelCase 경계, 공백 및 구두점을 정규화해 중복 후보 10개를 분리했다. 모델 입력의 원문은 바꾸지 않았다.
- 정상 원본의 `risk_instruction`을 위험 원본과 연결했다. 이것을 추가 학습 샘플로 만들어 개수를 늘리지 않았다.
- 기존 RoboJailBench와 SafeText의 프로젝트 선별 풀과 비교한 정규화 문자열 중복은 0개였다. 의미적 중복까지 없다는 뜻은 아니다.
- 기존 다국어 CLIP 토크나이저로 확인한 선별 입력의 최대 길이는 34토큰으로 128토큰 한도 이내다.

**후속 준비 완료:** 학습 366개, 검증 31개, 시험 32개로 분할하고 SafeAgentBench 전용 입력 검사와 CPU 임베딩 캐시를 연결했다. 실제 재학습은 아직 실행하지 않았다. [분할 기준과 실행 방법](f1t-safeagentbench-splits.md)을 참고한다. 후보 풀의 `split=UNASSIGNED`와 선별 요약의 `training_ready=false`는 선별 시점 기록이며, 실제 학습 입력은 `splits_v1/`에 별도로 저장했다.

이미지는 없으므로 기존 이미지+텍스트 F1-T에 그대로 합치지 않는다. `scene_name`도 실제 환경 설명이 아닌 시뮬레이터 장면 식별자다. 원본의 실행 단계와 정답 상태를 입력에 포함하지 않는다.

SafeAgentBench는 원래 벤치마크이므로 학습에 사용하는 사례는 이후 독립적인 벤치마크 평가에서 제외한다. 위험 범주 자체가 처음인 경우의 평가와 이미 학습한 범주의 새로운 상황 평가는 구분해야 한다.

## 산출물

프로젝트 경로: `data/safeagentbench_f1t_english_v1/`

- `review.html`: 검색과 상태 필터를 제공하는 검토표.
- `selected.jsonl`: 정상 247개와 위험 182개 후보.
- `review_ledger.jsonl`: 600개 전체 원장.
- `held.jsonl`, `excluded.jsonl`, `duplicates.jsonl`: 미선별 레코드와 사유.
- `summary.json`, `README.md`: 집계와 기준 설명.
- `source/`, `provenance.json`: 원본 파일과 출처 해시.
- `review_decisions.json`, `contrast_links.jsonl`: 판단 기록과 원본 비교 관계.

재현 스크립트: `scripts/prepare_safeagentbench.py`

```powershell
uv run --frozen --extra train --extra ocr python scripts/prepare_safeagentbench.py --input data/safeagentbench_f1t_english_v1 --output artifacts/f1t/safeagentbench-rebuild --baseline-root . --verify-tokenizer
```

재현 명령의 출력 경로는 존재하지 않는 새 디렉터리여야 한다. 모델 학습은 실행하지 않는다.
