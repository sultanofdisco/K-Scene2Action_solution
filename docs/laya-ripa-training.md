# Laya RIPA 추가 학습 결과

RIPA 결합 모델의 선택 체크포인트는 RIPA 검증에서 공격 탐지 100.0%, 정상 통과 0.0%, 정확도 50.0%였다. 정상 통과 문제가 해결되지 않아 실용적인 성능 개선을 확인하지 못했다. 공격 탐지만으로 학습 성공이라고 평가하지 않는다.

RIPA 공격을 기존 F1-O 학습 데이터에 결합하고, 같은 학습 조건의 기존 데이터 대조군과 비교했다. F1-T와 운영 모델은 바꾸지 않았다.

## 학습 내용

- 기존 58건 + RIPA 공격 180건 + 합성 정상 180건 = 418건.
- 검증은 기존 22건과 RIPA 90건으로 분리했다.
- RIPA 225개 원본 공격 중 SA03, SA08, SA14의 45건은 검증 전용이다. SA16과 SA17은 제외했다.
- 정상은 안전 안내, 공격 인용, 점검 기록으로 생성한 합성 자료다. 정답은 사람 검수 전이다.
- 원래 Laya multilingual의 scorer 592,897개 파라미터만 학습했다. 인코더와 decision head는 동결했다.
- AdamW, 6,000회 업데이트, 질문 행 256개 미니배치, seed 42, CPU 4스레드. 학습률은 0.001에서 0.00001까지 코사인 감소한다.
- 질문별 클래스 빈도 가중치를 각 실험의 학습 데이터에서 계산했다. 기존 데이터 대조군에도 동일한 알고리즘을 적용했다.

## 모델 선택

100회마다 두 검증 집합을 각각 평가했다. 두 집합 중 낮은 공격 탐지율을 먼저 높이고, 그 값이 같으면 공격 CLEAR 비율을 낮추고 정상 통과율의 집합별 평균을 높이는 순서로 선택했다. UNKNOWN은 공격 탐지 성공이 아니다. 초기 기본 모델도 후보에 포함했고, 기존 진단 결과로 다시 선택하지 않았다.

- 기존 58건 대조군: 0회 체크포인트 선택. 동결 가중치 유지 True, 전체 파이프라인 재실행 대조 8건 통과.
- RIPA 결합 418건: 300회 체크포인트 선택. 동결 가중치 유지 True, 전체 파이프라인 재실행 대조 8건 통과.

## 정상 문구가 막히는 위치

선택된 RIPA 모델이 정상 검증 45건에 답한 분포다. 앞의 세 질문 중 하나라도 YES면 공격이 된다. 네 번째 질문에서 정상 문구를 인식하더라도 앞의 오탐을 취소하지 않는다.

| 질문 | 정상 건수 | YES | NO | UNKNOWN |
| --- | --- | --- | --- | --- |
| harmful_instruction | 45 | 19 | 26 | 0 |
| task_override | 45 | 45 | 0 | 0 |
| authority_spoofing | 45 | 44 | 1 | 0 |
| benign_observation | 45 | 45 | 0 | 0 |

현재 실험만으로 실패 원인을 데이터 양 하나로 단정할 수 없다. 다음 진단은 데이터를 더 모으기 전에 작업 변경 및 권한 사칭 질문에서 정상 안내와 인용문의 정답을 학습할 수 있는지, 동결 특징과 scorer 학습 방식에 문제가 없는지 확인하는 것이다. 이번 결과를 보고 정답이나 검증 분할을 바꾸거나 후속 학습을 추가하지 않았다.

## 해석의 한계

RIPA 검증은 위험 목표를 분리했지만 문구 템플릿과 출처 역할은 공유한다. 새 환경의 독립 평가가 아니다. 이전 F1-T 학습에 관련 로컬 위험 목표가 포함된 적도 있다. 모든 수치는 원본 외부 관찰 문구를 직접 주입한 Laya 의미 판별 결과이며 OCR 성능이 포함되지 않았다. 기존 진단은 이전에도 사용한 합성 자료로, 모델 선택 후 회귀 확인에만 썼다. 검증에 반복적으로 선택한 결과이므로 별도 실환경 평가가 필요하다.

서비스 기본 모델은 교체하지 않았다. 두 체크포인트와 마지막 업데이트 가중치를 모두 보관했다. 마지막 가중치 결과는 `summary.json`의 `last`, 선택한 가중치 결과는 `selected`에 있다.
