# F2 구현 근거와 검증

> 이전 규칙 검사기 기록입니다. 현재 Contract 구조·검증 상태는 [F2 구현과 연결](F2_구현과_연결.md)을 기준으로 봅니다.

## 입력 자료와 구현의 관계

| 자료 | 구현에 반영한 내용 |
|---|---|
| 사용자 합의: VLA 제거, VLM → 좌표 어댑터 → Isaac Sim | 행동 계획 검사 위치와 실행 전달 경계 |
| 사용자 합의: 마스킹 제외, F1 입력 차단 | 입력을 수정하는 기능이나 F1 모델을 이 저장소에 추가하지 않음 |
| 「다양한 환경의 Harmful Action 정의 v1.0」, 2026-10-04 | 실제 피해와 후보·위험 상태 구분, 여덟 분류, 공간 진입 자체의 HA5 제외, 단순 위반과 피해 경로 구분 |
| 첨부 「sonnet_report_20261001 (1).md」 | 낙하 성공 사례 6개와 정상 계획에서도 발생한 경로 접촉을 회귀 범위·한계 설명에 사용 |
| 보고서에 연결된 실제 결과 JSON의 `model_plan` | `decision/steps/action/object/destination/reason` 입력 형식과 낙하 회귀 사례 |
| 보관된 `k2a_vlm_plan.py`, `k2a_plan_to_commands.py` | 기존 상위 `steps` 형식과 원본 계획의 직접 실행 구조 확인. 위험 실행 코드는 복사하지 않음 |

연결 JSON은 로컬 보관본 `bob-Scene2Action-static-watermark-20261003`에서 읽었다. 원본 저장소는 [bob-Scene2Action](https://github.com/8l4nnk/bob-Scene2Action)이며, 상대 경로와 원본 파일 SHA-256은 [출처 목록](../examples/recorded_sources.json)에 기록했다. 이 작업에서는 해당 원격의 현재 내용과 보관본이 일치하는지 별도로 확인하지 않았다.

추출본은 사례 ID와 `model_plan`만 포함한다. 실행 로그·영상·공격 입력 데이터 전체를 가져온 것이 아니다. [추출된 계획 6개](../examples/recorded_drop_plans.json)는 원본 VLM 응답의 계획 부분이며, 정상 계획·환경 설정은 별도로 만든 합성 예제다.

보고서의 성공은 별도의 `floor-drop-eval` 보조 환경에서 확인된 공 낙하다. 실제 사람 부상·실물 로봇 고장·기업 금전 손실로 해석하지 않는다. 정상 공 배치 과정의 도구 접촉은 실행 경로에서 발생했으므로, 계획 검사만으로 충돌을 완전히 방지한다고 주장하지 않는다.

## 확인하는 동작

테스트는 승인 작업의 정상 통과, 대상·목적지 불일치, 배치 횟수, 지지·경로 미확인, 힘·속도·시간 상한, 제어기 오류, 잘못된 숫자·JSON·필드, 문맥 불일치, 세부 행동 순서, 차단·보류 계획의 전달 금지를 검사한다. 두 공 정상 작업은 두 배치가 모두 완료되어야 통과한다.

낙하 기록 6개는 `FORBIDDEN_ACTION`으로 차단되는지 확인한다. 이는 등록된 배치 작업에서 낙하 명령을 허용하지 않는 정책의 회귀 검사다. 새로운 공격을 모두 탐지했다는 결과나 실제 Isaac Sim 재실행 결과는 아니다.

검증 명령:

```bash
python -m unittest discover -s tests -v
python demo.py
python -m f2 --plan examples/vlm_steps_two_balls.json --context examples/context_two_balls.json --format steps
```

## 아직 검증하지 않은 부분

실제 VLM API 호출, RunPod에서의 지연, 좌표 변환 어댑터, Isaac Sim 동작, D435i 관측, xArm 6·G2 제어기와의 연결은 이번 검증에 포함하지 않는다. 기존 어댑터가 정규화된 계획의 단위·상한을 적용하고 승인되지 않은 원본 계획 경로를 실행하지 않는지는 통합 단계에서 확인해야 한다.

ISO 원칙을 참고한다는 사용자 요구는 유지한다. 특정 표준의 판정 조항·적용 범위·검증 자료는 입력받지 않았으므로 적합성 인증이나 표준 수치 충족을 주장하지 않는다.
